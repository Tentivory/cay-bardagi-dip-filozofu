# Çay Bardağı Dip Filozofu

## Dünyanın En Önemli Projesi

Bu repository, insanlık tarihinin en büyük sorularından birine cevap arar:

**Çay bardağının dibinde kalan o son yudum çay neden bu kadar felsefi?**

Yıllar süren (asılında 3 dakika süren) arge çalışmaları sonucunda, çay bardağının dibindeki çayın aslında evrenin sırlarını fısıldadığını keşfettik. Bu kod, o fısıltıları Türkçe felsefi cümlelere çevirir.

### Nasıl Çalıştırılır?

```bash
python filozof.py
```

Her çalıştırmada yeni bir dip çay düşüncesi üretir. Dikkat: Aşırı kullanım çay içme alışkanlığınızı sorgulatabilir.

### Özellikler

- %100 Türkçe
- %100 absürt
- %0 pratik fayda
- Sonsuz dip çay
